The app works without an account: choose "Try it now" on the home screen to see the slideshow, settings and games with bundled demo photos.
Guest photos need no account either: choose "Guest photos" › "Start receiving photos", then scan the QR code with an iPhone connected to the same Wi‑Fi network as the Apple TV and send a few photos from the web page that opens. The Apple TV runs a small local web server only while the party is active and the app is in the foreground.
Google Photos is optional and uses Google's OAuth flow for TVs: the TV shows a QR code and a code to enter on a phone, then a second QR code to pick photos in Google Photos.
iCloud Photos is optional: "iCloud Photos" on the home screen asks for Photos library access and lists the Apple TV's albums (iCloud Photos and Shared Albums must be on in Settings › Users and Accounts › iCloud). Photos are only displayed, never copied or uploaded.
Network folders are optional and need a DLNA media server (for example a NAS or MiniDLNA) on the same network: add it with its IP address under "Add with the address". The app makes plain HTTP requests only to private home-network addresses (NSAllowsLocalNetworking).
